# **App Name**: Kintsugi Portal

## Core Features:

- User Authentication: Secure user authentication with distinct Guest and Admin roles.
- Dashboard: Display key business metrics in a comprehensive dashboard.
- Admin Panel: Manage users and system settings through a dedicated admin panel.
- About Us: Display information about the KINTSUGI variety shop

## Style Guidelines:

- Primary color: Warm gold (#D4A24E) to reflect Kintsugi's aesthetic.
- Background color: Sleek off-white (#F5F5F5) for a modern look.
- Accent color: Deep brown (#A67B5B) for highlighting key elements.
- Body font: 'PT Sans' for a modern, readable appearance.
- Headline font: 'Playfair' to create an elegant look for titles.
- Use of minimalist, line-style icons for navigation and key features.
- Clean, grid-based layout for easy content organization.
- Subtle transitions and hover effects to enhance user interaction.
